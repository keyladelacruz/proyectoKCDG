## 👩‍💻 Descripción

Este repositorio contiene mi portal personal profesional desarrollado como parte de las prácticas de Git.

El proyecto integra conocimientos de **HTML, CSS, Git y GitHub**, permitiendo organizar y administrar las diferentes versiones del sitio web.

---

## 📁 Archivos principales

- `index.html` - Página principal del sitio.
- `identidad.html` - Página de identidad personal.
- `css/style.css` - Hoja de estilos del sitio.
- `img/` - Carpeta que contiene las imágenes utilizadas.
- `varios/` - Carpeta de archivos adicionales.
